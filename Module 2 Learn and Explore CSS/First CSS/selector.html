Explore mixed selector

CSS helps style HTML elements on a webpage.

There are three main types of CSS: inline, internal, and external.

The class selector targets multiple elements with the same class name.

The id selector is used for a unique element on the page.

External CSS keeps your design separate from HTML, making the code cleaner.
